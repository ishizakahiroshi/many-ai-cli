はじめて入れる人へ

Windows なら、PowerShell に次の1行を貼り付けてください。

pnpm add -g many-ai-cli; pnpm exec many-ai-cli setup

セットアップが終わると、デスクトップに「Many AI Hub Start」と「Many AI Hub Stop」ができます。

次回からは「Many AI Hub Start」をダブルクリックするだけです。黒い画面は Hub 本体なので、使っている間は閉じずに最小化してください。

詳しい手順や、macOS・Linuxでの入れ方はこちらにまとめています。

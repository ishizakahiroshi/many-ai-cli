S-01 枠のパターン比較

Q1

承認待ちと未確認で停止を、どんな見せ方で目立たせるか

何を決めるか：カードをどんな見せ方で目立たせるかを選んでください。下の図は、どれも同じ 5 枚（実行中・承認待ち・未確認で停止・待機・選択中）です。

A　全周に枠をつけるおすすめ

承認待ちは橙の枠がゆっくり光り、未確認で停止は黄の枠が静かに付きます。

メリット：一覧を流し見したとき、カードの輪郭で気づけます。承認待ちは動き、停止は動かないので、急ぎの度合いも見分けられます。枠はカードの内側に描くので、カードの大きさは変わりません。

デメリット：承認待ちが何枚も同時に出ると、光る枠が並んでにぎやかに見えます。

改修の目安：変更 0.5 日・確認 0.5 日（概算）

B　カード全体を色で塗る

カードの背景を橙・黄で濃く塗ります。動きはありません。

メリット：枠より面積が広いので、遠くからでも色の違いが分かります。動かないので落ち着いて見えます。

デメリット：背景が濃くなり、カード内の文字や小さなラベルとの差が縮みます。

改修の目安：変更 0.5 日・確認 0.5 日（概算）

C　外側だけ光らせる（枠なし）

枠線は付けず、カードの外側に色の光だけを出します。承認待ちはゆっくり脈打ちます。

メリット：カードの中身の見た目は今のままで、周りだけが変わります。

デメリット：枠線がないので、光が弱く見えるテーマでは気づきにくくなる場合があります（S-04 で確認できます）。

改修の目安：変更 0.5 日・確認 0.5 日（概算）

D　今のまま

承認待ちは薄い背景と左の橙バー。未確認で停止は丸が黄色になるだけです。

メリット：見慣れた表示のまま変わりません。

デメリット：未確認で停止は丸 1 つの色だけなので、流し見では気づけません（今回の相談の原因です）。

改修の目安：変更なし

おすすめの理由：承認待ち（今すぐ操作が要る）は動く枠、未確認で停止（見るだけ）は静かな枠と、急ぎの度合いで見せ方を変えられるのは A だけです。

いつ決めるか：作り込みに入る前（急ぎではありません）。

直るまでの防ぎ方：決まるまでは今の表示のままで、丸の色と旗のアイコン、タブの数字で見分けられます。

S-02 色の比較

Q2

枠に使う色（承認待ち・未確認で停止）

何を決めるか：承認待ちと未確認で停止の枠に使う色の組を選んでください。パターンは Q1 の選択（今のままを選んでいるときは A）で描いています。

A　橙＋黄おすすめ

承認待ちは濃い橙、未確認で停止は明るい黄にします。

メリット：2 色が並んでも見分けやすく、「橙は今操作が要る、黄は見るだけ」と直感で分かれます。ご希望の橙・黄とも同じです。

デメリット：橙は Claude のアイコンの色（#fb923c）に近く、Claude のセッションが並ぶと、アイコンと枠の色が似て見えます。

改修の目安：色の指定だけなので、Q1 の変更に含まれます。

B　橙＋水色

承認待ちは橙、未確認で停止は穏やかな水色にします。

メリット：橙との差が最も大きく、「終わって静かに待っている」印象と合います。

デメリット：水色は Codex のアイコンの青（#60a5fa）に近く、Codex のセッションでは枠とアイコンの色が似て見えます。

改修の目安：色の指定だけなので、Q1 の変更に含まれます。

C　今の色（琥珀＋黄）

今の画面の警告色（承認待ち）と黄色（未確認で停止）をそのまま使います。

メリット：ゲージの警告や親セッションの印など、ほかの警告表示と同じ色にそろいます。

デメリット：2 色の色相がとても近く（上の図の数字）、並ぶと見分けにくくなります。

改修の目安：変更なし

おすすめの理由：2 色の意味（今すぐ・見るだけ）が色の違いで読み取れ、どちらも「注意」の暖色にそろうのは A です。

いつ決めるか：作り込みの途中でも変えられます（S-05 で好きな色にできます）。急ぎではありません。

直るまでの防ぎ方：決まるまでは今の色のままです。

S-03 重なり方の比較

Q3

色ラベル・選択中の枠と、状態の枠が重なるときの優先順

何を決めるか：利用者が付けたカードの色ラベル、子セッションの印、選択中の青い枠が、状態の枠と重なるときの優先順を選んでください。図の 4 枚は「承認待ち＋緑のラベル」「未確認で停止＋青のラベル」「承認待ちの子セッション」「承認待ち＋選択中」です。未確認で停止は、開くと消えるので選択中とは重なりません。

A　状態を優先し、色ラベルは左バーに残すおすすめ

枠は状態の色にします。色ラベルは左端のバーに残り、選択中は外側に青い細い輪が残ります。

メリット：承認待ちに気づけて、どのセッションかも左バーの色で分かります。選択中でも承認待ちが隠れません。

デメリット：色ラベルを枠で見分けていた人は、状態が付いている間だけ枠の色が変わって見えます。

改修の目安：変更 0.5 日・確認 0.5 日（概算）

B　状態の色で全部上書きする

状態が付いている間は、枠も左バーも状態の色にします。

メリット：見た目が単純で、状態がいちばん強く出ます。

デメリット：状態が付いている間は、色ラベルがカードのどこにも出ません。

改修の目安：変更 0.5 日・確認 0.5 日（概算）

C　今のまま

色ラベルが枠のままで、承認待ちは左バーだけが橙になります。選択中のカードは承認待ちでも青のままです（CSS の並びから読んだ挙動で、実画面では未確認）。

メリット：色ラベルがいつも枠に出ます。

デメリット：状態の枠を足せないので、今回の目的（流し見で気づく）が叶いません。

改修の目安：変更なし

おすすめの理由：「状態に気づく」を最優先にしながら、色ラベルも残せるのは A だけです。

いつ決めるか：作り込みに入る前（急ぎではありません）。

直るまでの防ぎ方：決まるまでは今の表示のままです。

S-04 テーマ別の見え方

Q1〜Q3 の選択（）を、アプリで選べるテーマに写しました。Dark と Light は標準、あとの 4 つは「カスタムテーマ」（色相とコントラストを動かす機能）の例です。カスタムテーマは背景の色味だけが変わり、警告色（橙・黄）は土台の Dark / Light のままです（theme-tokens.ts 冒頭の記述）。

枠の色と背景の明暗差（計算値）

各テーマのカード背景（色づけ前）に対する、枠の色のコントラスト比です。3 以上を○にしています（図形や枠線が背景と区別できる目安として広く使われる値）。同じ並びで暗い画面の色と明るい画面の色をそれぞれ使います。

S-05 作り込みパネル

色・太さ・背景の色づけ・光り方を自由に動かして、気に入った組み合わせを「設定メモ」として出せます。メモはそのまま次の作業の指示に貼れます。

# #P-20261020-004 独立レビュー指示

目的は、[README.md](README.md) の仕様に対する実差分と失敗経路の確認。実装者とは別の担当が、初回指示公開 commit から実 code SHA までの差分を読む。文書と生成物を無関係差分と誤認しない。

## 見る観点

1. **標準表示が変わっていないこと**: 標準のカードのマークアップ・CSS・挙動の差分が無い。`git diff` の対象ファイルで示す。B 方式（コンパクト用の行を別関数で組む）を選んだとき、標準の組み立て関数を共有して壊していない
2. **呼び出し元の洗い出し**: カードの部分更新（`.card-done-slot` ほか、`session-list.ts` の `querySelector`）が、コンパクトの行でも要素を取りこぼさない。カードのクリック・キーボード・右クリック・ドラッグの処理（`session-list.ts`、`session-list-tabs.ts`）が、新しい行の要素でも動く
3. **ヘッダー**: 権限モードが空のセッションと git 外のセッションでチップが出ない。ブランチのクリックがカードの `.card-branch` と同じ経路を通っている（処理の複製が無い）。ブランチ値が変わったとき、`renderSessionInfoChip` が再描画される。幅が狭いときの省略
4. **判定関数**: D1 のとおり。空と値が混ざるケース、同数で割れるケース、1 件だけのグループ、親子を含むグループの数え方。fixtures の期待値が仕様の文章と一致している
5. **ポップ**: 遅延タイマーとポップが、再描画・スクロール・カーソルが外れたとき・タブ切替のときに残らない。`c.dataset.tooltip` と二重に出ない。下の行を押し下げない。キーボードのフォーカスでも内容が読める
6. **設定**: 端末ごとの保存で、サーバー同期の対応表に載っていない。他の設定の保存（全体の PUT）が新しい値を消さない・書き換えない。起動時と切替時に反映される
7. **i18n**: `ja.json` / `en.json` / `vi.json` に同じキーが揃っている。使われていないキー・足りないキーが無い
8. **fixtures の実行**: 新しい fixtures が `web/package.json` の `test` の列挙に入っており、CI のログで実行されている
9. **個人情報**: fixture・コメント・文書に、個人パス・ホームパス・メールアドレス・実在のプロジェクト名が入っていない
10. **範囲**: `rust/`・`go/`・フッター・セッション帯・CI workflow・依存に差分が無い

## 提出

- review 対象の code SHA、再現手順と重大度つきの指摘、実行した command とその結果、未検証の範囲
- 修正後の新しい SHA は影響範囲を検査し直す。**古い PASS を引き継がない**
- 指摘なしでも、対象範囲を書く
- 管理 Issue にコメントする

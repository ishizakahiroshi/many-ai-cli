# #5 C1 独立レビュー

対象はINSTRUCTIONS.mdの固定版と、その指示commit以降のC1文書・HTML差分。指示commitを含むPR自体に指示書が載るのは正常。実装者とは別の担当がレビューし、対象SHAを記録する。

確認項目：

- 六つの比較対象とポーリングの接続先差分が説明され、流れ図が往路・復路・AI起動・保存を表している。
- メリット・デメリットが共通の軸で比較され、第一候補・次点以降の理由と未確認条件がある。
- 公式仕様・ソース上の能力・実測が区別され、本人のSlack投稿の成功をBot間通信の成功にすり替えていない。
- Socket Modeのイベント範囲、DMとメンション、切断補完、Webhookの受信条件、GitHub CLI転送の用途制限を現行一次資料で確認している。
- HTTP/MCP/A2A対応や現在のHubの外部イベント起動・セッション再開を、根拠なく可能と断定していない。
- ソース基準と別件Rust移植を分け、非公開のローカル資料・秘密・本人環境のパスに依存していない。
- C2の順位順の実験、失敗の理由記録、次点移行、共通原因の切り分け、上限・後片付けが具体的。
- HTMLが単体で表示でき、図・モバイル幅・比較表・リンクを確認した証跡と未実施事項がある。
- 変更が許可された文書と、必要なomitnix生成索引に限定され、C2実験や設定変更を始めていない。

指摘の重要度・根拠・必要な修正を返す。修正があれば修正後SHAを再確認する。文書レビュー完了は接続実験や本番運用の成功を意味しない。

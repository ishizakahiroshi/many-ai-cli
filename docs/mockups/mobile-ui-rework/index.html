優先度 (体感への効きどころ)

順位論点体感への効き実装規模
1A. ヘッダー密集常時目に入る・操作起点なので全機能の印象を底上げ中
2E. 入力欄 FAB 被り送信ごとに発生する摩擦。直すと入力速度が体感で変わる小
3F. Safari セーフエリア誤タップで Safari 操作が暴発する事故を防ぐ (CSS だけで済む)小
4C. ターミナル空行過多可視行数が増えるとログ追跡の往復が減る中
5B. タブ右切れWorkbench が見えないのは機能の発見性に直接影響小
6D. 詳細ボタン位置視線の流れ改善・アイコン化で常駐コストを下げる小

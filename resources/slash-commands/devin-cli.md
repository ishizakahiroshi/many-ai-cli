# Devin CLI Slash Commands

| Command | Purpose | When to use it |
|---|---|---|
| `/accept-edits` | Switch to accept-edits permission mode. | When you want Devin to apply edits without asking. |
| `/add-dir` | Add a working directory for file access. | When Devin needs files from an external directory. |
| `/archive` | Archive a cloud session. | When cleaning up finished cloud sessions. |
| `/ask` | Switch to ask-only mode. | When you want answers without code changes. |
| `/auth` | Manage authentication settings. | When checking or changing sign-in options. |
| `/billing` | Show billing information. | When checking plan or usage charges. |
| `/btw` | Ask a quick side question. | When you need clarification without changing the thread. |
| `/bug` | Report a bug to the Devin CLI developers. | When something breaks and you want it recorded. |
| `/bypass` | Switch to bypass-permissions mode. | When running autonomous work without prompts. |
| `/clear` | Clear the conversation display. | Start a clean view without leaving the session. |
| `/cloud` | Manage cloud sessions. | When moving work between local and cloud. |
| `/compact` | Summarize and compact the conversation. | Reduce context usage while keeping important details. |
| `/config` | Open CLI configuration. | Review or change config values. |
| `/context` | Show current context usage. | When you want to see where your context window is going. |
| `/continue` | Continue the most recent session. | Pick up where the last conversation left off. |
| `/dangerous` | Switch to dangerous permission mode. | When you accept fully unrestricted tool use. |
| `/desktop` | Continue the session in the desktop app. | When switching from CLI to desktop. |
| `/diff` | Open a diff viewer of uncommitted changes. | When reviewing what code changed during a session. |
| `/exit` | Exit the CLI. | When ending a session. |
| `/export` | Export the current conversation. | When you want to save the conversation to a file. |
| `/fast` | Toggle fast mode. | When you want faster output on supported models. |
| `/handoff` | Hand the session off to the cloud. | When continuing local work in a cloud session. |
| `/help` | List commands and show help. | Check available commands and usage. |
| `/hook` | Manage hook configurations for tool events. | When managing automation and tool permissions. |
| `/hooks` | View hook configurations for tool events. | When reviewing automation and tool permissions. |
| `/knowledge` | Manage knowledge entries. | When updating what Devin remembers. |
| `/list` | List sessions. | When picking an earlier conversation to resume. |
| `/list-sessions` | List sessions. | When picking an earlier conversation to resume. |
| `/login` | Sign in to Devin services. | Authenticate the CLI in a new environment. |
| `/login-status` | Show login status. | When checking which account is signed in. |
| `/logout` | Sign out of Devin services. | Remove authentication from this environment. |
| `/ls` | List sessions. | When picking an earlier conversation to resume. |
| `/mcp` | Manage MCP server connections. | When configuring external tools and data sources. |
| `/mode` | Switch session mode. | Change between normal, plan, and other modes. |
| `/model` | Open the model selector. | Switch models for speed, quality, or cost tradeoffs. |
| `/new` | Start a new conversation. | When beginning an unrelated task. |
| `/normal` | Switch to normal permission mode. | When returning to default approval prompts. |
| `/open` | Open a cloud session. | When pulling a cloud session into this terminal. |
| `/plan` | Enter plan mode. | When you want to review planned changes before execution. |
| `/playbook` | Manage playbooks. | When running saved task procedures. |
| `/plugins` | Manage installed plugins. | When configuring or troubleshooting extensions. |
| `/quit` | Exit the CLI. | When ending a session. |
| `/remove-dir` | Remove a working directory. | When revoking file access from an added directory. |
| `/resume` | Resume a prior conversation. | Continue work from an earlier thread. |
| `/review` | Review the current diff or changes. | Before shipping code or when you want feedback. |
| `/rm-session` | Remove a saved session. | When deleting old conversations. |
| `/rules` | Manage project rules. | When updating instructions Devin follows. |
| `/secret` | Manage secrets. | When adding or rotating stored credentials. |
| `/session-stats` | Show session statistics. | When checking token or cost usage for this session. |
| `/shell` | Toggle shell mode. | When you want to run commands directly. |
| `/skills` | List available skills. | When discovering what skills are installed. |
| `/smart` | Switch to smart permission mode. | When balancing autonomy and prompts. |
| `/stats` | Show usage statistics. | Review limits and ongoing usage trends. |
| `/status` | Show current status. | Inspect account, connectivity, and runtime state. |
| `/thinking` | Toggle extended thinking. | When you want the model to think longer before responding. |
| `/undo` | Undo the last change. | When reverting a recent action. |
| `/undo-add-dir` | Undo a previously added directory. | When reverting an add-dir change. |
| `/update` | Update the CLI. | When a newer version is available. |
| `/upgrade` | Open the upgrade page. | When switching to a higher plan tier. |
| `/workspace` | Show workspace information. | When checking the active workspace. |
| `/workspaces` | Manage workspaces. | When listing or switching workspaces. |
| `/yolo` | Switch to yolo permission mode. | When accepting all actions without prompts. |

# Command Code Slash Commands

| Command | Purpose | When to use it |
|---|---|---|
| `/add-dir` | Manage extra working directories in scope. | When you need files from a directory outside the current workspace. |
| `/agents` | Manage agent configurations. | When you want to view or adjust available agents. |
| `/changelog` | Show what changed in the latest release. | When you want to see recent updates to Command Code. |
| `/clear` | Start a new session with empty context. | When you want a clean slate while keeping the previous session resumable. |
| `/clone` | Clone the current branch into a new session. | When you want to branch off into a separate session without touching the original. |
| `/compact` | Compact the conversation history. | When you want to reduce context usage while keeping key details. |
| `/compact-mode` | Choose the strategy used to compact sessions. | When you want to change how conversation history gets compacted. |
| `/config` | Search and change Command Code settings. | When you want to adjust settings such as which model runs a task. |
| `/connect` | Connect additional AI providers or API keys. | When you want to add a BYOK provider or configure API keys. |
| `/context` | Show context window usage and its breakdown. | When you want to see how much of the context window is in use. |
| `/copy` | Copy the last response to the clipboard. | When you want to reuse the assistant's last reply elsewhere. |
| `/courses` | Open Command Code courses in your browser. | When you want to learn more through guided courses. |
| `/design` | Open the design partner for UI work. | When you want to audit, build, compose, or ship a UI. |
| `/effort` | Set the reasoning effort for the current model. | When you want to trade response depth against speed. |
| `/exit` | Exit Command Code. | When you are done working and want to leave the session. |
| `/export` | Export the session to html, jsonl, or markdown. | When you want to save or share the conversation as a file. |
| `/extra` | Open the billing page to buy on-demand credits. | When you have run out of plan credits and want more. |
| `/feedback` | Report a bug or share feedback. | When you want to open a prefilled GitHub issue for Command Code. |
| `/fork` | Fork the conversation into a new session. | When you want to explore a different path without altering the original session. |
| `/goal` | Set an objective for the agent to work towards. | When you want the agent to keep working until a stated goal is met. |
| `/help` | Display help information. | When you need a reminder of available commands and usage. |
| `/hotkeys` | Show all keyboard shortcuts. | When you want to learn the available shortcuts. |
| `/ide` | Connect your IDE to share the open file and selected lines. | When you want the agent to see what you have open in the editor. |
| `/import` | Import setup such as skills, agents, commands, MCP, and memory from another coding agent. | When migrating your configuration from another coding agent. |
| `/init` | Initialize AGENTS.md for this project. | When setting up project guidance for Command Code to follow. |
| `/learn-taste` | Learn your taste from sessions with other coding agents. | When you want Command Code to pick up your style from past work in another tool. |
| `/login` | Log in to Command Code. | When authenticating your account in a new environment. |
| `/logout` | Log out of Command Code. | When you want to remove the current authentication from this environment. |
| `/mcp` | Manage MCP server connections. | When configuring external tools and data sources. |
| `/memory` | Manage Command Code memory. | When you want to review or update what the agent remembers. |
| `/mode` | Show or switch the permission mode. | When you want to change between default, auto-accept, or plan mode. |
| `/model` | Switch between Command Code models. | When you want to change models for speed, quality, or cost. |
| `/name` | Show or set the current session name. | When you want to check or change the session's display name. |
| `/plan` | Enter plan mode for the session. | When you want to review a planned approach before execution. |
| `/plan-review` | Review the session's latest plan. | When you want to check the current plan before acting on it. |
| `/plans` | Browse, review, and annotate saved plans. | When managing plans saved across sessions. |
| `/pr-comments` | Fetch all PR comments for the current branch. | When you want the agent to see reviewer feedback on your PR. |
| `/quit` | Exit Command Code. | When you are done working and want to leave the session. |
| `/reload` | Restart Command Code and resume this session. | When applying a staged update without losing your session. |
| `/rename` | Rename the current session. | When you want a memorable label for the session. |
| `/resume` | Resume a past conversation. | When you want to continue work from an earlier session. |
| `/review` | Review a pull request. | When you want the agent to analyze changes in a PR. |
| `/rewind` | Restore the session to a previous checkpoint. | When you want to undo recent changes and conversation. |
| `/session-file` | Show the current session id and its on-disk file path. | When you need the session file location for support or debugging. |
| `/sessions` | Resume a past conversation. | When you want to continue work from an earlier session. |
| `/share` | Share the conversation as a gist. | When collaborating or sharing your session with others. |
| `/skills` | Browse and open agent skills. | When checking which skills are available to the agent. |
| `/status` | Show comprehensive environment status. | When checking account, connectivity, and runtime state. |
| `/taste` | Manage Taste learning and its usage. | When you want to review or adjust how the agent learns your style. |
| `/terminal-setup` | Set up editor keybindings for Command Code. | When configuring your editor to work with Command Code. |
| `/theme` | Switch between dark and light themes. | When customizing the visual appearance of the CLI. |
| `/todos` | Manage the session todo list. | When tracking or clearing tasks within the current session. |
| `/trace` | Copy the current trace id to the clipboard. | When you need the trace id for support debugging. |
| `/tree` | Browse the session tree. | When you want to jump to an earlier point in the conversation. |
| `/unshare` | Stop sharing the conversation. | When ending collaborative access to your session. |
| `/update` | Update Command Code to the latest version. | When you want to pick up the newest release. |
| `/upgrade` | Open the billing page to upgrade your plan. | When you want to move to a higher plan tier. |
| `/usage` | Display credits, plan, and usage metrics. | When reviewing limits and ongoing usage trends. |
| `/worktree` | Create, list, or switch isolated git worktrees. | When juggling multiple branches without changing your working directory. |
